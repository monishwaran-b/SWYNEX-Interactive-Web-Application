## 📌 About the Project

**SWYNEX** is an interactive web application designed to deliver a modern, user-friendly, and engaging digital experience.

The project focuses on modern web technologies, clean architecture, responsive design, and an intuitive user interface.

## ✨ Features

- 🎨 Modern and attractive user interface
- ⚡ Fast and responsive application
- 📱 Responsive design
- 🔥 TypeScript-based development
- 🧩 Modular project structure
- 🚀 Built using Vite for faster development

## 🛠️ Technologies Used

| Technology | Purpose |

| TypeScript | Application development |
| Vite | Build tool and development server |
| HTML5 | Web structure |
| CSS3 | Styling |

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/monishwaran-b/SWYNEX-Interactive-Web-Application.git
```

### 2. Navigate to the Project Folder

```bash
cd SWYNEX-Interactive-Web-Application
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Open the local URL displayed in your terminal.
